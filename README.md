# Тренажёр по аудиту

Отдельное приложение для подготовки по бухгалтерскому учёту, аудиту,
отчётности и налогообложению. В репозитории находится собственная копия
движка, поэтому изменения здесь не меняют приложение для собеседований.

## Запуск и сборка

```bash
pnpm install
pnpm dev
pnpm build:single:audit
pnpm type-check && pnpm lint && pnpm test
```

GitHub Pages публикует однофайловую сборку из `dist-audit`. Деплой запускается
при push в `main` и вручную через GitHub Actions.

## Структура

- `src/engine/` — интерфейс и движок заданий;
- `src/content/audit/` — вопросы, теория, карточки, инструменты и план;
- `src/demos/audit/` — интерактивные демонстрации.

Сборка `build:single:audit` встраивает только пак аудита в один HTML.
